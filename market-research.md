# Developer Market Research

## 1. Chosen Niche

### Target Role

**Full-Stack Web Development — Junior/Entry-Level Full-Stack Developer**

I chose Full-Stack Web Development as my target niche because I want to work across both the frontend and backend sides of web applications. This path allows me to use my existing knowledge of HTML, CSS, JavaScript, databases, Git, and programming while continuing to develop stronger skills in modern frameworks, APIs, backend development, testing, and deployment.

The purpose of this research is to identify the technologies and skills that employers are actually requesting in junior and entry-level Full-Stack Developer positions. The learning priorities and roadmap in this assignment are therefore based on the patterns found in the job listings rather than on general technology trends.

### Frequency Analysis Interpretation

The strongest pattern across the listings is the repeated combination of **frontend development, backend development, APIs, and databases**. React appears frequently on the frontend side, while Node.js appears repeatedly on the backend side. REST APIs are also a recurring requirement, showing that the ability to connect frontend applications with backend services is important for junior Full-Stack roles.

Relational databases and SQL also appear repeatedly, indicating that database knowledge is an important part of Full-Stack development rather than an optional skill.

JavaScript and TypeScript are also important because they appear across multiple listings and support both frontend and backend development in several of the researched roles.

Next.js appears in several listings and is particularly relevant to my learning path because it combines frontend development with backend capabilities and is used by companies hiring junior Full-Stack developers.

Testing, CI/CD, and cloud platforms appear less frequently than the core development skills. However, they still appear in the research and should therefore be included in the learning roadmap after the fundamental Full-Stack skills are strengthened.


## 4. Pattern Analysis

### Essential Skills

Based on the frequency analysis, the strongest priorities for a junior Full-Stack Developer are:

- JavaScript
- React
- Node.js
- REST APIs
- SQL and relational databases
- Git/GitHub
- TypeScript

These skills appeared repeatedly across the researched listings and represent the core of the Full-Stack development workflow.

### Secondary Skills

The research also identified several skills that are valuable but appeared less consistently:

- Next.js
- Python/FastAPI
- HTML/CSS
- Testing
- CI/CD
- Cloud platforms such as AWS
- Tailwind CSS

These skills should be developed after the core frontend, backend, API, database, and version-control skills are solid.

### Less Common Skills

Some technologies appeared only once or twice, including:

- Docker/Kubernetes
- NoSQL
- Vue/Nuxt
- WebSockets and real-time systems

These technologies are useful, but the research does not provide enough evidence to make them the main focus of a six-month junior Full-Stack learning plan.

### What Surprised Me

One interesting finding was that the listings were not focused only on writing frontend code. Even junior positions frequently expected developers to understand APIs, databases, backend development, debugging, testing, deployment, or production issues.

Another observation was that companies did not all use the same frontend framework. React was the most recurring frontend technology in the researched listings, while Vue/Nuxt also appeared in some positions. This suggests that strong JavaScript and Full-Stack fundamentals are more important than learning every framework.

The research also showed that deployment, monitoring, testing, and collaboration skills become relevant even at the junior level. This means that becoming employable as a Full-Stack Developer requires more than simply learning how to build a website.


## 5. Current Skill Gaps

Comparing the job requirements with my current profile, I already have experience with several foundational technologies, including HTML, CSS, JavaScript, PHP, MySQL, Git, and general programming.

However, the research shows that I should strengthen several areas to become more competitive for junior Full-Stack positions.

My main areas for improvement are:

- React and modern frontend development
- TypeScript
- Node.js backend development
- REST API development
- Modern SQL/database development
- Next.js
- Automated testing
- CI/CD and deployment
- Cloud fundamentals
- Debugging and production monitoring

The biggest priority is not to learn all of these technologies simultaneously. Instead, I should build a strong Full-Stack foundation first and then gradually add testing, deployment, and cloud skills.


## 6. Conclusion

The job-market research confirmed that Full-Stack Development is a suitable direction for my career goals. The strongest recurring requirements were frontend development with React and JavaScript, backend development with Node.js, REST APIs, databases and SQL, Git/GitHub, and TypeScript.

The research also changed my priorities by showing that I should focus less on collecting many different frameworks and more on becoming capable of building, testing, connecting, and deploying complete applications.

The next six months will therefore focus on strengthening these core skills and demonstrating them through practical portfolio projects that reflect the responsibilities found in the job listings.
