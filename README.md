# TechTalks Assignment 2 — Developer Market Research

## Target Niche

**Full-Stack Web Development — Junior/Entry-Level Full-Stack Developer**

This assignment analyzes the current developer job market to identify the skills and technologies most frequently requested for junior Full-Stack Developer positions.

The research focuses on seven real job listings and uses their requirements to create a focused six-month learning roadmap and portfolio plan.

## Research Summary

The research showed that the strongest recurring requirements for junior Full-Stack Developer positions include:

- React
- Node.js
- REST APIs
- SQL and relational databases
- JavaScript
- TypeScript
- Git/GitHub

Other skills such as Next.js, testing, CI/CD, cloud platforms, and Python/FastAPI appeared less consistently but remain useful secondary skills.

The research influenced the learning plan by prioritizing core Full-Stack development skills first, followed by testing, deployment, CI/CD, and cloud fundamentals.

## Goal

The goal of this assignment is to turn real job-market evidence into a focused career development plan rather than attempting to learn every technology associated with Full-Stack Development..
