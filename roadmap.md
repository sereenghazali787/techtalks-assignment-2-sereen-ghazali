# Six-Month Learning Roadmap

## Roadmap Goal

Based on the seven Full-Stack Developer job listings analyzed in my market research, my main goal for the next six months is to become a stronger junior Full-Stack Developer with the ability to build, test, and deploy complete web applications.

The roadmap prioritizes the technologies and skills that appeared most frequently in the job listings instead of trying to learn every technology mentioned.

The main priorities are:

1. JavaScript and TypeScript
2. React
3. Node.js
4. REST APIs
5. SQL and relational databases
6. Git/GitHub
7. Next.js
8. Testing
9. CI/CD and deployment
10. Cloud fundamentals

---

## Month 1 — Strengthen JavaScript, TypeScript, Git, and Web Fundamentals

### Goals

- Strengthen JavaScript fundamentals.
- Improve understanding of asynchronous JavaScript.
- Learn TypeScript fundamentals.
- Strengthen HTML and CSS and responsive design.
- Improve Git and GitHub workflow.

### Topics

- Modern JavaScript (ES6+)
- Functions, objects, arrays, modules
- Promises and async/await
- Error handling
- TypeScript types, interfaces, generics, and basic utility types
- Git branches, commits, merges, and pull requests
- Responsive HTML/CSS

### Practical Work

Build a small responsive web application using JavaScript/TypeScript and Git.

### Outcome

By the end of Month 1, I should be comfortable writing structured JavaScript/TypeScript code and using Git/GitHub as part of my normal development workflow.

---

## Month 2 — React and Frontend Development

### Goals

- Develop stronger React skills.
- Learn how to build reusable and maintainable frontend components.
- Improve responsive user-interface development.

### Topics

- React components
- Props and state
- Hooks
- Forms and validation
- Conditional rendering
- Lists and reusable components
- React Router
- API data fetching
- Responsive design
- Basic frontend error handling

### Practical Work

Build a React application that consumes data from an external or mock REST API.

### Outcome

By the end of Month 2, I should be able to build a complete responsive React frontend and connect it to an API.

---

## Month 3 — Node.js, REST APIs, and Backend Development

### Goals

- Strengthen backend development skills.
- Learn how to design and build REST APIs.
- Understand how frontend and backend applications communicate.

### Topics

- Node.js
- Express.js
- REST API design
- HTTP methods and status codes
- Routing
- Middleware
- Authentication fundamentals
- Authorization
- Input validation
- Error handling
- Environment variables

### Practical Work

Build a backend REST API with authentication and connect it to the React application from Month 2.

### Outcome

By the end of Month 3, I should be able to develop a functional backend and connect it to a frontend application through REST APIs.

---

## Month 4 — SQL, Databases, and Next.js

### Goals

- Strengthen relational database skills.
- Learn how to design and query databases.
- Develop practical Next.js skills.

### Topics

- SQL fundamentals
- Database design
- Tables and relationships
- Primary and foreign keys
- Joins
- CRUD operations
- PostgreSQL or MySQL
- Database integration with Node.js
- Next.js fundamentals
- Server-side and client-side concepts
- Next.js routing and API capabilities

### Practical Work

Build a full-stack application using React/Next.js, Node.js, and a relational database.

### Outcome

By the end of Month 4, I should be able to create a complete application that stores and retrieves real data from a relational database.

---

## Month 5 — Testing, Debugging, and Deployment

### Goals

- Learn how to test applications.
- Improve debugging skills.
- Understand the basics of deploying web applications.

### Topics

- Unit testing
- Integration testing
- API testing
- Jest/Vitest fundamentals
- Playwright basics
- Debugging frontend and backend applications
- Logging
- Production error handling
- Deployment fundamentals
- Environment configuration

### Practical Work

Add automated tests to the full-stack project and deploy it to a suitable hosting platform.

### Outcome

By the end of Month 5, I should be able to test, debug, and deploy a full-stack application instead of only running it locally.

---

## Month 6 — CI/CD, Cloud Fundamentals, and Portfolio Preparation

### Goals

- Understand basic CI/CD workflows.
- Learn essential cloud and deployment concepts.
- Complete and polish portfolio projects.
- Prepare projects for job applications.

### Topics

- GitHub Actions
- Continuous Integration and Continuous Deployment
- Basic AWS or another cloud platform
- Deployment workflows
- Environment variables and secrets
- Basic application monitoring
- Code review practices
- Documentation
- Project README files

### Practical Work

Create a CI/CD workflow for a portfolio project, improve its documentation, and make sure the application is deployed and accessible.

### Outcome

By the end of Month 6, I should have a small portfolio of complete, documented, tested, and deployed Full-Stack projects that demonstrate the skills identified in my job-market research.

## Final Roadmap Principle

The main focus of this roadmap is depth rather than collecting technologies. The first four months focus on the core Full-Stack development skills that appeared repeatedly in the researched job listings. Testing, deployment, CI/CD, and cloud skills are introduced afterward so that they can be applied to applications I already know how to build.

Technologies that appeared less frequently, such as Kubernetes, advanced NoSQL systems, and real-time technologies, will not be major priorities during these six months. They can be explored later depending on the requirements of specific jobs I apply for.
